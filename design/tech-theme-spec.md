# Codex Connect 深色科技风

状态：历史备选方案。用户已要求继续采用原浅色淡紫设计；当前源码已恢复浅色，此文档不再是实施规范。

面向初次配置模型的 Windows / macOS 用户。保留“添加模型 → 确认 → 保存”的流程，以及“我的模型”“设置”两个次入口。科技感来自深色层次、冷色强调、清晰边界，不增加仪表盘、装饰指标或技术术语。

## 调整依据

| 旧版问题 | 本版处理 |
| --- | --- |
| 白底、浅紫、大圆角更接近普通设置工具 | 深海蓝底色，青绿色操作按钮，8px 控件与 12px 卡片圆角 |
| 当前选择主要依靠底色 | 导航增加左侧强调线；服务卡片保留勾选与边框 |
| 硬编码浅色使控件主题不一致 | 统一输入框、下拉列表、备份列表、代码预览与状态样式 |
| 深色设计可能降低说明可读性 | 说明使用浅灰蓝，逐项计算对比度 |

## 字体与组件

| 层级 | 桌面字号 | 设计稿字号 | 字重 |
| --- | --- | --- | --- |
| 页面标题 | 20pt | 28px | 粗体 |
| 卡片标题、导航 | 10pt | 14–15px | 标题粗体 |
| 正文、表单 | 9pt | 13–14px | 常规 |
| 辅助提示 | 8pt | 12px | 常规 |

Windows 使用 Microsoft YaHei UI，macOS 使用 PingFang SC；代码详情使用 Consolas / Menlo。系统字体保持中文阅读和平台兼容性。网页行高 1.6，桌面使用既有控件度量与布局。主操作高度 44px，表单框内边距 13px；小窗口内容区可滚动，底部操作栏固定。

主按钮青绿色；次按钮深色描边；禁用态降低对比；键盘聚焦使用明确边框，主按钮聚焦改用浅白描边。选中服务保留勾选符号。自定义模型直接显示名称、模型、地址、密钥表单；保存后名称用于区分模型。系统文件选择与消息弹窗仍使用操作系统外观。
