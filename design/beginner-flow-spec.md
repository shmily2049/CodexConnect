# 浅色设计下的新手流程

2026-10-19：按用户要求继续使用原浅色背景、淡紫强调色与三项主导航。深色科技风不再应用。以下记录为 0.10.4 历史设计；当前版本 0.10.8 的变更见文末。交互稿是 CodexConnect-0.10.4-preview.html。旧 beginner-preview 保留为历史稿。桌面实现以 src/desktop_ui.py 为准，HTML 仅演示交互，不读写配置、不请求服务。

## 首次使用

首次打开配置助手显示“开始使用 Codex”，已有 Codex 配置也显示引导。两项选择为“使用 ChatGPT套餐”和“连接其他模型”。前者进入“我的模型”中的账号入口，点击引导不会直接切换、写入模型配置或重启；后者进入预填服务表单。允许跳过，设置页可随时重新打开。

用户作出选择后，只在所选配置的同级目录创建 `.codex-connect-welcome` 标记，使用排他创建，不覆盖已有文件。标记只记是否看过引导，不保存密钥或其他个人信息；无法写入时不阻止使用。每个配置目录独立记忆。引导标记的隔离文件检查已在历史完整桌面回归中通过；不代表操作过用户的真实配置。

## 密钥帮助

表单标签为“访问密钥（API Key）”。“如何获取密钥？”先打开说明窗口，再由用户选择是否访问服务商网站。说明匹配服务和套餐，网关模型明确使用 OpenRouter 的密钥。自定义模型说明需从服务商取得哪些资料，不提供猜测的网站链接。只使用现有预设的受控链接，不将用户输入作为外部跳转地址。

帮助窗口可滚动，支持 Escape 关闭。说明不要求安装开发工具或编写代码；保留按量计费、套餐密钥、测试可能产生费用等必要信息。

## 中文报错

错误显示简短标题、原因与下一步。401 引导重新填写密钥；403 提醒检查权限和套餐；404 检查模型与地址；429 提醒等待或检查额度，不武断断言余额不足。文件损坏、冲突、锁定等情况保持原有停止写入的保护，不自动覆盖或删除文件。

底部按钮可定位密钥、模型、地址或高级字段；切换输入或状态后清除旧处理按钮。未知异常不直接显示原始内容，避免泄漏密钥和服务器响应。弹窗与底部状态提供文字说明，不仅依赖颜色。

## 高级设置

默认显示使用帮助、备份和预览入口。环境变量、地址、配置位置、上下文、服务标识和清单集中在默认折叠的“高级设置”。展开/收起不重置值。校验定位到高级字段时自动展开并滚动到该字段。

## 当前模型与账号

“我的模型”顶部显示“配置已选择”、当前配置中的模型标签，以及“Codex 实际运行：尚未核实”。配置读取失败时不得保留旧的选中状态。已选择卡片置顶，淡紫底与紫色边框，按钮为禁用的“✓ 已选择”；其他卡片显示“切换到此模型”或“切回套餐”，经确认后才保存。

不以 Codex 左下角账号标签或模型自报身份证明实际请求路由。切换后需要完全重启 Codex 并新建会话。自动重启选项默认关闭；启动成功只证明进程启动，不能证明模型已生效。原账号登录由 Codex 管理，本工具不改登录缓存。

## 作者与帮助入口

侧栏保留版本 0.10.4，去掉作者文字，直接显示 src/assets/author-qr.png 原图的缩略图。点击二维码可放大，关闭或 Escape 返回；缩略图按钮支持键盘激活。设置的使用帮助区域增加“PDF 使用说明”。

## 0.10.6 模型名称同步
保持原有视觉和表单，不增加必填项。下一步只在内存准备模型清单；确认保存时写入带内容哈希的本地清单。自定义模型以原始模型 ID 作为 Codex 显示名称（不改大小写、路由或密钥）。已有清单不原地覆盖，能力和提示词保留；无清单使用通用默认配置。切换旧方案同样补齐名称清单。切回 ChatGPT套餐恢复其原始清单或默认内置列表。明确提示完全重启 Codex 后在新会话查看。

0.10.7：我的模型支持编辑与删除。编辑后“保存并使用”，旧方案不重复保留；同一地址密钥留空可继续使用旧密钥，改地址须重新填写。删除仅从方案列表移除，保留配置备份和同服务共用凭据；当前方案先切换再删除。ChatGPT套餐是固定入口。目录和发行命名统一 CodexConnect，Windows 测试包位于 release/CodexConnect-0.10.7/。


0.10.8：修复切回套餐时遗留 OpenAI 地址覆盖（确认后恢复默认地址）、配置与方案状态共同恢复、新增入口残留编辑状态、旧式 profile 兼容性校验和 Windows 独立 PDF 打包。方案独立存储，旧版历史在确认写入时导入；备份列表显示时间、模型变化与恢复状态。关闭窗口或切换服务时保护未保存输入，保存后可直接测试已保存方案，同服务凭据修改会提示受影响方案。支持紧凑窗口、响应式服务卡片与键盘焦点滚动。Mac 仍仅静态包检查，未完成真机、签名、公证。


0.10.11：同页从编辑转新增会清除编辑目标，未保存改动仍先确认。编辑页显示“编辑模型 / 检查修改”。我的模型支持名称、服务商及地址搜索，仅过滤内存中的已读方案；分页按搜索结果计算。切换准备移到后台，重用本次已验证的方案集合，保存前仍重新检查配置及方案状态，过期结果不弹确认框。读取时明确显示正在读取当前配置，失败提供处理方向。未完成、空白或异常类型的文字回复不能通过连接测试。损坏备份单独标记且禁止恢复，不中断其他条目。


0.10.12：切换“国内模型 / 国际模型”时首次选中第一项，再次切回恢复本次打开期间该分组上次选择的服务商，并同步模型默认值。切换分组前确认未保存的改动；取消保持原页签、输入和预览。重复点击当前分组不重置表单。这里只切换填写对象，确认保存后才修改实际配置。


## 0.10.13 编辑一致性与操作反馈

- 编辑绑定配置快照及模型列表版本；任一发生外部改动时，重新选择后才能保存。
- 历史服务地址与现有 Provider 地址不同，要求重新连接；更换编辑地址不能沿用原环境变量或留空继承旧 Key。
- 编辑、预览、删除先在后台读取，UI 保持可操作；扫描期间修改输入或取消等待后不应用旧结果。保存仍需确认和最终并发校验。
- 载入当前配置成功后才替换编辑上下文；载入失败保留输入、目标、预览及测试状态。
- 套餐 / 地域下拉框先确认再提交选择；取消和重复选择保留原输入、预览及测试状态。
- 备份页进入时自动刷新，支持仅看可恢复条目及打开目录；不可恢复条目显示原因，恢复按钮禁用，核心恢复仍重新校验。
- 诊断摘要仅含版本、系统、页面及固定错误类别，不含地址、路径、原始异常或凭据。
